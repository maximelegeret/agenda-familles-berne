Scope: docs/index.html (+ app.js, style.css, textes_fr.json), the whole agenda page. Mode: Operate.
Audience/job: a parent on a phone, children beside them, deciding what to do now or soon. Constraints: static page, real events only, French UI, illustrations authored (no source photos).

## Direction contract

THESIS: A warm consumer app, not a listings page: what starts soon is a big illustrated card you can act on; the rest is a calm, thumb-reachable list. Refuses the category default of identical white event rows under a tab strip.

OWN-WORLD: Warm apricot-tinted ground, white soft cards (large radius, soft offset shadow), one saturated action colour (tomato) only on things you can press. Each activity type owns a muted tint and an authored two-tone spot illustration (conte, atelier, spectacle, musique, visite, nature, sport, fête). Rounded humanist sans (Figtree, self-hosted), tabular figures for times. Bernese header scene (Zytglogge, arcades, Aare) as one authored SVG.

STORY: Open → see the next activity and how soon it starts → glance at the rest of today → switch to week-end or open filters from the bottom bar → tap a card for details and the source link.

FIRST VIEWPORT: Header with the Bern scene and a plain-language title; a large "Bientôt" card (illustration, "dans 40 min", title, place, age/price chips); a horizontal row of the next 2–4 as smaller illustrated cards; start of the day list. Bottom bar fixed: Aujourd'hui / Week-end / 14 jours segmented + Filtres button.

FORM: Challenger "digital-design-canon-warm-consumer-app-surface" chosen by the user over the assigned Bernese arcades; seed: f37bbb3492581fab. Signature move: the "Bientôt" hero card with live relative time; press = soft spring.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
